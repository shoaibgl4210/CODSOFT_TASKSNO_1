# Calculator

A responsive calculator built with HTML, CSS and vanilla JavaScript for the CodeSoft Front-End Web Development internship.

## Features
- Addition, subtraction, multiplication and division
- Decimals, percent (%), sign toggle (±), clear (C) and delete (⌫)
- Chained calculations (e.g. 2 + 3 × 4 evaluates left to right)
- Divide-by-zero error message
- Full keyboard support: digits, + − * /, Enter or =, Backspace, Esc or C, %
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in any browser. No build step or dependencies.
